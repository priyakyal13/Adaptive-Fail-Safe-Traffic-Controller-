# Verification report (Verilog version)

## What changed from the SystemVerilog version

Every module was rewritten in plain Verilog (IEEE 1364-2005) — `logic`
replaced by `reg`/`wire`, `always_comb`/`always_ff` replaced by
`always @(*)`/`always @(posedge clk or posedge rst)`, typed parameters
made untyped, and the testbench's implicit `.*` port connections written
out explicitly. No functional behavior was changed in this rewrite.

The reset fix from the SystemVerilog version is carried over unchanged:
reset lands in `ALL_RED` (fail-safe), not `NS_GREEN`.

## Compile verification

Compiled and run in this environment with Icarus Verilog (`iverilog`,
v12.0), using `-g2005` — the strict plain-Verilog mode, which rejects any
SystemVerilog-only syntax at compile time. A clean compile under this
flag is a genuine guarantee the source is pure Verilog.

```bash
iverilog -g2005 -Wall -o sim/flowguard.out rtl/*.v tb/*.v
vvp sim/flowguard.out
```

Result: clean compile, zero warnings, all checks passed.

## Checks actually run in this environment

- Reset asserts `ALL_RED` with both directions red; `ns_green`/`ew_green`
  never high while `rst` is asserted. **Confirmed.**
- High demand (`traffic_ns = 7`) with `MIN_GREEN=2`, `MAX_GREEN=6`
  produces a green phase of exactly **6** cycles. **Confirmed.**
- A direction with `traffic == 0` accumulates no wait debt and is never
  selected over a demanding direction. **Confirmed.**
- The wait counter saturates at `MAX_WAIT` and does not overflow it.
  **Confirmed.**
- Every clock cycle (outside reset), exactly one of
  `{ns_red, ns_yellow, ns_green}` and exactly one of
  `{ew_red, ew_yellow, ew_green}` is asserted, and NS/EW are never both
  green. **Confirmed over a 200+ cycle mixed-demand run.**
- Forcing an illegal state code onto `safety_monitor` immediately forces
  both directions to red (`fault` asserted). **Confirmed.**

Output:

```text
OK: NS green duration = 6 cycles (clamped to MAX_GREEN)
OK: illegal state correctly forced fail-safe all-red
ALL SANITY CHECKS PASSED
```
